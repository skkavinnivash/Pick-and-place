How MediaPipe Hand Tracking Works in this App

1. Landmarks: Track 21 3D hand keypoints extracted from video stream.
2. Virtual Cursor: Landmark 8 (Index finger tip) maps directly to screen X & Y.
3. Pinch Calculation: Euclidean distance between Landmark 4 (Thumb) and Landmark 8:
dist = Math.hypot(thumb.x - index.x, thumb.y - index.y)
4. Drag & Drop: When dist < 0.055, pinch activates, picking up card and dropping when released!
💡 Camera Note: Camera permission is requested only when the user clicks "Hand Cam". If no webcam is available or permission is declined, the game automatically runs with smooth mouse / touch drag-and-drop.
